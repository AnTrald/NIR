# Отчёт этапа 0

Дата исходного отчёта: 18 ноября 2026 года. Итог согласования добавлен 20 ноября 2026 года в конце файла. Ниже до раздела дополнения сохранён исторический отчёт до согласования; его отметки об открытых решениях относятся к 18 ноября.

**Этап:** 0 — архитектурное проектирование. Статус: проект подготовлен для рассмотрения; этап ещё не принят заказчиком.

**Цель:** изучить основное ТЗ и подготовить технический проект, достаточный для согласования до написания приложения.

**Реализовано:** полностью прочитан `master_prompt.md` (1187 строк); обследована рабочая папка; подготовлены анализ требований, архитектура, спецификация `.webnb`, модель данных, контракты API, модели обоих движков, протокол консоли, модель угроз и план проверок. Созданы четыре Mermaid-диаграммы: компоненты, сохранение, ER-модель, запуск. Функциональность приложения не реализовывалась.

**Архитектурные решения:** требования Next.js + FastAPI + PostgreSQL, клиентское выполнение, JSONB и полная пересборка зафиксированы как заданные ТЗ. Новые решения не объявлены согласованными. Рекомендуются общий origin с фиксированным proxy; серверные сессии; строгий формат; отдельные classic scripts в общей области видимости; HTML body-фрагменты; статический sandbox-runner с собственной CSP; атомарная revision. Альтернативы и последствия перечислены в журнале.

До изменений найден только основной файл ТЗ; указанные каталоги были пусты, применимых AGENTS.md не найдено. Отсутствие совпадений rg возвращало код 1; это не результат тестирования приложения.
3. `git status --short` завершился кодом 1: `fatal: not a git repository`. Git не инициализировался, diff/status получить нельзя.
4. `Get-FileHash -LiteralPath 'master_prompt.md' -Algorithm SHA256` до и после создания проекта: `241974CB245CA9C2012A6EA1080B2FC51637E34F0F5DD8D2AA0CFABB8613B596`. ТЗ не изменён.

PowerShell-аудит: наличие всех 11 обязательных документов, локальные Markdown-ссылки через Test-Path, парность code fences, JSON-примеры через ConvertFrom-Json, наличие FR-01–FR-15, отсутствие символа замены UTF-8 и файлов приложения. Первый запуск: 11 документов, 16 локальных ссылок, 4 JSON-примера, 4 Mermaid-блока; одна ошибка — ссылка testing.md на ещё не созданный этот отчёт. После добавления отчёта проверка повторяется; окончательные результаты записаны ниже.
6. Проверены официальные материалы HTML Standard, CSP, OWASP, JSON Schema, Pydantic, PostgreSQL и Next.js. Ссылки расположены рядом с соответствующими обоснованиями. Чтение документации не подтверждает работу будущей реализации или совместимость версий.

**Результат повторной проверки:** код завершения 0, ошибок нет. Проверены 12 Markdown-документов (11 обязательных и отчёт), 28 локальных ссылок и 4 JSON-примера. Найдены 4 Mermaid-блока с парными Markdown-ограждениями и все FR-01–FR-15. В frontend/backend 0 файлов; SHA-256 исходного ТЗ не изменился. Первоначальная ошибка ссылки устранена созданием отчёта.

**Тесты:** тесты приложения не писались и не запускались: кода приложения и зависимостей ещё нет. Проверен синтаксис JSON-примеров, но это не тест будущего валидатора `.webnb`. Mermaid не рендерился и не проверялся отдельным parser. Docker, БД, API, UI, браузеры, CSP и безопасность исполнения не проверялись. Число упоминаний FR подтверждает формальное покрытие документацией, а не выполнение функциональных требований.

**Проблемы:** буквальное требование полного запрета сетевых запросов не обосновано обычным iframe с произвольным JS; P-007 остаётся открытым. Не гарантируется прекращение бесконечного цикла таймером. Версии зависимостей и конфигурация среды ещё не выбраны и не проверены. Рабочая папка пока не Git-репозиторий.

**Критерии приёмки:** все 12 задач этапа 0 и 14 пунктов представления архитектуры из раздела 15 раскрыты в проектных документах. Приложение не начато; решения ТЗ и предложения разделены. Не выполнены согласование новых решений и закрытие вопроса P-007. Этап 0 нельзя считать принятым, а критерии готовности MVP — реализованными.

**Следующий этап:** после принятия проекта можно отдельно представить на разрешение этап 1 — выбор версий и инфраструктура. Одно согласование архитектуры не трактуется как автоматическое разрешение программировать. До нового сообщения заказчика работа остановлена на этапе 0.
