1. Рекомендуемое: сохранить scripts/init-env.ps1 в UTF-8 с BOM, сохранив русские сообщения. Исправление может выполнить агент; после него повторить прямой запуск в PowerShell 5.1.

3. Использовать PowerShell 7 с явным запуском через pwsh, если он установлен. Установка новой оболочки ради одного скрипта не требуется при выборе первого варианта.
